## Descripción

Este repositorio reúne las prácticas y evidencias de la materia **Desarrollo Móvil Integral**. Los ejercicios aplican los fundamentos de desarrollo multiplataforma con **Flutter** y **Dart**, desde la revisión de la metodología de evaluación hasta la creación de interfaces con estado, aplicaciones multimedia y catálogos de widgets interactivos.

Cada práctica tiene su propio README con el objetivo, descripción y, cuando corresponde, instrucciones de ejecución y evidencias.

🔄 Providers (Riverpod)

🔢 counterProvider

Contador simple de tipo int usando StateProvider. Se incrementa reactivamente desde CounterScreen usando ref.read.

final counterProvider = StateProvider<int>((ref) => 5);

🎨 themeNotifierProvider

StateNotifierProvider que envuelve ThemeNotifier. Controla el color seed activo y el modo oscuro/claro del tema global.

final themeNotifierProvider =
StateNotifierProvider<ThemeNotifier, AppTheme>(
(ref) => ThemeNotifier(),
);

🎭 ThemeNotifier

Clase controladora que extiende StateNotifier<AppTheme>. Expone métodos toggleDarkmode() y changeColorIndex(int).

class ThemeNotifier extends StateNotifier<AppTheme> {
void toggleDarkmode() => state = state.copyWith(...);
void changeColorIndex(i) => state = state.copyWith(...);
}

🌈 colorListProvider

Provider inmutable que expone la lista de colores disponibles (colorList) para que ThemeChangerScreen la renderice con RadioListTile.

final colorListProvider =
Provider((ref) => colorList);
